# EzUtilities
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-blue)](http://makeapullrequest.com) [![License: MIT](https://img.shields.io/badge/License-MIT-blue)](https://ebukaracer.github.io/ebukaracer/md/LICENSE.html)

A Unity package that provides collection of reusable runtime utilities for robust Unity projects.

[View in DocFx](https://ebukaracer.github.io/EzUtilities)

## Features
- **EzUtilities.Core** provides core scripts and helpers.
- **EzUtilities.Common** provides common scripts and helpers.

## Installation
| Package Name       | URL                                                  | How to Install using the Package Manager                                           |
| ------------------ | ---------------------------------------------------- | ---------------------------------------------------------------------------------- |
| EzUtilities.Core   | https://github.com/ebukaracer/EzUtilities.git#core   | Select **Install package from git URL** and enter the *package url* inside the box |
| EzUtilities.Common | https://github.com/ebukaracer/EzUtilities.git#common | ✓                                                                                  |

## Notes
- The packages can be removed using the package manager
- Check out their API references [here](https://ebukaracer.github.io/EzUtilities)
